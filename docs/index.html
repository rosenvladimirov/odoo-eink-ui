Какво правиWhat it does

Модул за Odoo 18, който оптимизира бекенда за E Ink таблети — BOOX Note Max 13.3″, reMarkable и подобни. Включва се при нужда с ?eink=1 в URL-а, точно както ?debug=1. An Odoo 18 module that optimizes the backend for E Ink tablets — BOOX Note Max 13.3″, reMarkable and similar. Activated on demand with ?eink=1 in the URL, exactly like ?debug=1.

  • Тема — черно върху бяло, без сенки, анимации, преходи и заоблявания; контури вместо запълвания; само системни шрифтове. Theme — black on white, no shadows, animations, transitions or rounded corners; borders over fills; system fonts only.
  • Рисуване в html полета — OWL компонент с редактора js-draw (MIT): писалка, гума, текст, селекция, undo/redo, мащаб. Drawing in html fields — an OWL component hosting the js-draw editor (MIT): pen, eraser, text, select, undo/redo, zoom.
  • Отхвърляне на дланта — рисува само pointerType === 'pen'; докосването панорамира и мащабира. Palm rejection — only pointerType === 'pen' draws; touch pans and zooms instead.
  • Чувствителност на натиска — през Pointer Events API; BOOX Pen 2 Plus (Wacom EMR) я подава нативно. Pressure sensitivity — via the Pointer Events API; BOOX Pen 2 Plus (Wacom EMR) reports it natively.
  • Съхранение като SVG — рисунката влиза направо в стойността на полето. SVG е валиден HTML5, така че записът се отваря нормално и извън E Ink режим. SVG storage — the drawing goes straight into the field value. SVG is valid HTML5, so the record renders normally outside E Ink mode too.

Инсталация и употребаInstall and use

cd /path/to/addons
git clone -b 18.0 https://github.com/rosenvladimirov/odoo-eink-ui.git

Обнови списъка с приложения и инсталирай „Odoo E Ink UI". После отвори произволен бекенд адрес с добавено ?eink=1: Update the app list and install "Odoo E Ink UI". Then open any backend URL with ?eink=1 appended:

https://myodoo.example.com/odoo?eink=1

Параметърът се запазва при навигация чрез history patch — сесията остава в E Ink режим, докато не го махнеш. The parameter is preserved across navigation by a history patch — the session stays in E Ink mode until you drop it.
